# Zyntry Code

AI coding tasks in VS Code — you keep the editor, Zyntry does the legwork.

**What it does**

- Click the **Z** icon in the activity bar to open the Zyntry panel.
- Describe what you want ("add tests for auth", "refactor this module").
- Zyntry plans the work, executes stage by stage in your open folder, and
  shows the diff, verification results, and cost when it's done.
- **Free models included** — runs on free edge models with zero setup.
  For premium models, add your own OpenAI / OpenRouter / Anthropic key
  from the model picker (it stays on your device).
- High-risk tasks ask for your approval before anything is written.

**Install**

1. Install the extension from the VS Code Marketplace.
2. Reload VS Code and click the **Z** icon. That's the whole setup.

**Settings**

- `zyntry.backendUrl` — service endpoint (default is the hosted Zyntry service).
- `zyntry.runnerPollSeconds`, `zyntry.runnerMaxFiles` — local runner options.
